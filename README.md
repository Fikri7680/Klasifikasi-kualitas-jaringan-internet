# Klasifikasi Kualitas Jaringan Internet

Project Machine Learning untuk mengklasifikasikan kualitas jaringan internet (Buruk, Sedang, Baik) menggunakan algoritma **Random Forest Classifier**.

> **Catatan:** Dataset yang digunakan dalam project ini adalah data sintetis yang dibuat untuk keperluan pembelajaran.

### 📊 Hasil & Visualisasi
Hasil evaluasi model disimpan di folder `hasil/`:
- Confusion Matrix
- Distribusi Kelas Kualitas
- Feature Importance (Faktor paling berpengaruh ke kualitas jaringan)
